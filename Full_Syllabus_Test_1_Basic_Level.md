### GA Q.1 *(1 Mark | SCQ)*

The taxi charges in a city comprise of a fixed charge, together with the charge for distance covered. For a journey of **16 km**, the charges paid are **₹156** and for a journey of **24 km**, the charges paid are **₹204**. What will a person have to pay for travelling a distance of **30 km**?

- (A) ₹236
- (B) ₹240
- (C) ₹248
- (D) ₹252

> **✅ Answer: (B) ₹240**
>
> Let fixed charge = F, per-km rate = r.
> F + 16r = 156  ...(1)
> F + 24r = 204  ...(2)
> Subtracting: 8r = 48 → **r = 6**, F = 60
> For 30 km: 60 + 30 × 6 = **₹240**

- (A) 21
- (B) 27

> a₂ – 3 = k → a₂ = k + 3
> a₃ × 3 = k → a₃ = k/3
> a₄ ÷ 3 = k → a₄ = 3k

> → 5k + k/3 = 64 → 16k/3 = 64 → **k = 12**
> Numbers: a₁=9, a₂=15, a₃=4, a₄=36
> Largest – Smallest = 36 – 4 = **32**

### CS Q.5 *(1 Mark | SCQ)*

Consider the following code:

```c
void fun(int n) {
    int p = 0;
    for (int i = 0; i * i < n; i++)
        for (int j = i; j < log(i); j++)
            p = p + 1;
    return p;
}
```

What is the time complexity of function `fun()`?

- (A) O(n² log n)
- (B) O(n)
- (C) O(n log n)²
- (D) O(√n)

> **✅ Answer: (D) O(√n)**
>
> **Outer loop:** runs while i² < n → i goes from 0 to √n → **√n iterations**
>
> **Inner loop:** runs from j = i to j < log(i). For this to execute, we need log(i) > i.
> - i=0: log(0) undefined → 0 iterations
> - i=1: log(1) = 0 < 1 → 0 iterations
> - i=2: log(2) ≈ 1 < 2 → 0 iterations
> - For all i ≥ 2: log(i) < i → inner loop **never executes**!
>
> Only the outer loop does any meaningful work (checking condition) → **O(√n)**

A 24-bit physical address space has a **4-way set associative cache** of **64 KB** with a block size of **8 bytes**. The total size of tags in the cache directory is ________ K bits.

> **✅ Answer: 80**
>

> Sets = 8192 / 4 = 2048 = 2¹¹ sets

> Total tag bits = 8192 × 10 = 81,920 bits = **80 K bits** (approx)

### CS Q.24 *(2 Marks | NAT)*

> **(B):** ¬(p→q) ≡ p ∧ ¬q. So (B) = (p∧¬q) → ¬q. When premise is true (¬q is true), conclusion ¬q is true. **Always true** → tautology ✓
> (C): The consequent is ¬r which depends on r — not always true.

### CS Q.52 *(2 Marks | NAT)*

```c
#include <stdio.h>
int foo(int n) {
    if (n & (n-1))
        return 1 + foo(n/2);
    return 1;
}
int main() {
    printf("%d", foo(48));
}
```

The output of the above program is ________.

> **✅ Answer: 6**
>
> `n & (n-1)` is 0 only when n is a power of 2.
> foo(48): 48 & 47 = 32 ≠ 0 → 1 + foo(24)
> foo(24): 24 & 23 = 16 ≠ 0 → 1 + foo(12)
> foo(12): 12 & 11 = 8 ≠ 0 → 1 + foo(6)
> foo(6): 6 & 5 = 4 ≠ 0 → 1 + foo(3)
> foo(3): 3 & 2 = 2 ≠ 0 → 1 + foo(1)
> foo(1): 1 & 0 = 0 → return **1**
> Result = 1+1+1+1+1+1 = **6**

### CS Q.53 *(2 Marks | NAT)*

```c
int GridAccumulator(int matrix[][2], int rows, int multiplier) {
    int aggregate = 0;
    int r, c;
    for (r = 0; r < rows; r++) {
        for (c = 0; c < 2; c++) {
            aggregate = multiplier * aggregate + matrix[r][c];
        }
    }
    return aggregate;
}
```

Let M be a 3×2 array such that **M[r][c] = c + 1** for all valid indices r and c.
The value returned by **GridAccumulator(M, 3, 2)** is ________.

> **✅ Answer: 84**
>
> M = [[1,2],[1,2],[1,2]] (c+1, so col0=1, col1=2)
> Trace (multiplier=2):
> r=0,c=0: agg = 2×0 + 1 = 1
> r=0,c=1: agg = 2×1 + 2 = 4
> r=1,c=0: agg = 2×4 + 1 = 9
> r=1,c=1: agg = 2×9 + 2 = 20
> r=2,c=0: agg = 2×20 + 1 = 41
> r=2,c=1: agg = 2×41 + 2 = **84**

### CS Q.48 *(2 Marks | NAT)*

Let A ∈ ℝⁿˣⁿ be a real square matrix with eigenvalues λ₁, λ₂, ..., λₙ. Consider the following statements:
